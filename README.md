# DGC

DG-LAB 郊狼 / 负鼠 / 灵猫 三设备联动的网页游戏合集。

纯个人非商业作品，基于 [dungeonlab-open](https://github.com/dungeonlab-open) 开源协议与 [dglab-kit](https://github.com/dungeonlab-open/dglab-kit) SDK 开发。

## 功能

- **单机弹幕**：Boss 掉落核心果实，吟唱拾取强化弹幕（射速/弹道/护盾/移速升级链），双 Boss 波
- **电击消消乐**：在线双人，消除自动触发六色效果互坑，胜者实时掌控败者设备输出
- **恶魔轮盘**：6 弹巢俄罗斯轮盘博弈，实弹数量公开、顺序保密
- **账户体系**：注册登录、昵称与 ID 分离、战绩/徽章（铸造/转赠/加强锁定）
- **在线社交**：大厅聊天、邀战、随机匹配（可不限游戏）、徽章展示墙
- **局内沟通**：端到端加密私聊与图片、WebRTC P2P 语音（帧级加密）
- **设备设置**：基础/郊狼/负鼠/灵猫分区调节；每游戏独立个人设置；合成音效

## 运行

```bash
npm install
npm run dev        # 开发（前端 5210 + 房间服务器 8787）
npm run build      # 构建到 dist/
npm run server     # 单独运行对战房间服务器（默认 8787 端口）
```

Node.js 22+。所有游戏行为必须登录账号（服务端 SQLite 存储，密码 scrypt 哈希）。

## 自部署

前端构建产物是纯静态文件，房间服务器是单进程 Node（HTTP API + WebSocket 同端口）。参考拓扑：

- 静态站点：任意静态托管（子路径部署时对战地址默认同域 `/dgws` 反代）
- 房间服务器：Node 22 常驻（如 systemd），仅监听本机端口，由 nginx/网关反代 `wss://`
- 必配 HTTPS/WSS：账户令牌与信令只走加密传输
- 自定义服务器地址：改 `src/ui/battle-lobby.ts` 顶部 `SERVER_URL` 后构建

排行榜/徽章数据在服务器本地 `server/dgc.db` 与 `server/stats.json`，备份即复制文件。

## 安全

- 顶栏红色 ■ 紧急停止：清空所有设备任务、双通道归零；页面关闭/切后台自动清理
- 强度唯一出口：min(原始值 × 全局倍率, 系统上限, 100 红线, APP 舒适上限)
- 战败惩罚可随时认输停止；惩罚强度只在败者自己设置的范围内
- 首次使用务必低倍率逐项手动测试
- 电脉冲设备存在固有风险，请遵守 DG-LAB 官方安全指引，身体不适立即停止

## 设备接入

通过官方 V4 WebSocket 中继（默认 `wss://trex.dungeon-lab.cn/v4`）与 DG-LAB 4 APP 通信；支持自部署中继（设备弹窗 → 服务器地址连接）。
