# DGC

DG-LAB 郊狼 / 负鼠 / 灵猫 三设备联动的网页游戏合集：单机弹幕 + 在线宝石对战（消消乐法术对战）。

纯个人非商业作品，基于 [dungeonlab-open](https://github.com/dungeonlab-open) 开源协议与 [dglab-kit](https://github.com/dungeonlab-open/dglab-kit) SDK 开发。

## 运行

```bash
npm install
npm run dev        # 开发（默认 5210 端口）
npm run build      # 构建到 dist/
npm run server     # 对战房间服务器（默认 8787 端口）
```

Node.js 22+。

## 模式一：单机弹幕

- WASD/方向键移动，自动射击，空格/B/灵猫捏压放炸弹
- 受击 → 郊狼电击 + 负鼠振动；低血量 → 持续警告；死亡 → 爆发
- Esc 退出游戏，P 暂停

## 模式二：宝石对战（在线双人）

标题界面点「宝石对战」→ 创建房间得 4 位房间码，对方输入房间码加入。

**玩法**：
- 8×8 五色宝石消除，消除攒对应颜色能量，连锁（掉落再消）充能翻倍
- 法术（各耗 10 能量）：
  - ⚡ 电击对方（红）——对方承受值上升、其郊狼被电击
  - 🛡 护盾（蓝）——10 秒内被电减半
  - 💚 净化（绿）——降低自己承受值
  - ❄ 时停（黄）——冻结对方棋盘 5 秒
  - 🟣 紫色消除累积倍率（最高 ×3），停手衰减
- 4 连生成条纹炸弹（清整行/列），5 连生成彩虹球（清同色）
- 承受值先到 100 者战败 → 进入战败惩罚：随机波形持续输出、强度随轮数升级，**点击「认输」才停止**

**规则**：双方各自扫码连接自己的郊狼（设备控制本地化，对方无法直接控制你的设备）；网络只传施法/承受值/结算稀疏事件。

## 云服务器部署（线上配置实录）

线上地址：**https://walksunlight.com/dg/**（对战地址自动默认为 `wss://walksunlight.com/dgws`，玩家零配置）。

同一台阿里云 ECS 上还跑着 nginx + Next.js 博客（占用 80/443 根路径），游戏挂在子路径 `/dg/` 下，两者互不影响：

- 静态文件：`/var/www/dg/dist`（博客 nginx 的 443 server 块里 `location /dg/` alias）
- 房间服务器：`127.0.0.1:8787`，systemd 服务 `dg-room`（开机自启、崩溃自重启）
- Node 22 装在 `/opt/node22`（独立目录，**不碰系统 Node 18**——博客 next-server 依赖它）
- nginx 改动：`/etc/nginx/sites-available/sunlight-blog` 443 块内追加 `/dg/` 与 `/dgws` 两段，备份为 `.bak-20261001`；安全组只需 80/443，**不放行 8787**
- 国内网络：Node 二进制和 npm 依赖走的 npmmirror 镜像

**日常更新部署**（只改了前端）：

```bash
npm run build
scp -r dist root@<ECS_IP>:/var/www/dg/
```

改了 `server/` 才需要 `ssh root@<ECS_IP> 'systemctl restart dg-room'`。
`server/stats.json`（排行榜数据，不入库）在服务器本地，重装前记得备份。

## 设置说明（游戏设置弹窗）

- **波形池**：chip 多选，每次触发从池里随机抽一个波形
- **强度范围**：最小 ~ 最大 内随机取值，再 × 全局倍率，钳制到 APP 舒适上限
- **战败惩罚**：波形池 + 强度范围 + 升级间隔 + 每轮增量；有「测试惩罚 10 秒」按钮
- 所有设置实时生效并存 localStorage

## 安全

- 顶栏红色 ■ 紧急停止：清空所有设备任务、双通道归零；页面关闭/切后台自动清理
- 战败惩罚可随时认输停止；强度受全局倍率 × APP 舒适上限双重钳制
- 首次使用务必低倍率逐项手动测试
- ⚠️ 电脉冲设备存在固有风险，请遵守 DG-LAB 官方安全指引，身体不适立即停止

## 设备接入

通过官方 V4 WebSocket 中继（默认 `wss://trex.dungeon-lab.cn/v4`）与 DG-LAB 4 APP 通信，页面打开即自动连接、二维码随时就绪；支持自部署中继（设备弹窗 → 服务器地址连接）。
